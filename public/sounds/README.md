# Hiệu ứng âm thanh (SFX) — dùng ở Giai đoạn 4

Đặt các file `.mp3` / `.ogg` vào thư mục này:

| Sự kiện trong game            | Tên file gợi ý     |
| ----------------------------- | ------------------ |
| Xúc xắc lăn lộc cộc           | `dice-roll.mp3`    |
| Quân cờ nhảy qua ô            | `hop.mp3`          |
| Mua đất / xây công trình      | `build.mp3`        |
| Nhận tiền / ăn tiền           | `cash.mp3`         |
| Trả lời đúng                  | `correct.mp3`      |
| Trả lời sai                   | `wrong.mp3`        |
| Đếm ngược 5 phút cuối         | `tick-warning.mp3` |
| Thâu tóm đất đối thủ          | `takeover.mp3`     |
| Phá sản                       | `bankrupt.mp3`     |
| Kết thúc ván / công bố hạng   | `fanfare.mp3`      |

Dùng nguồn miễn phí bản quyền (Freesound, Pixabay, Mixkit) và giữ mỗi file dưới ~100 KB.
